The setup: You spread the same number of yeast cells on each plate. Each yeast cell that survives grows into a colony (a dot of many cells). Some colonies are a different color. A different color means a mutation in a color gene.
Control: the 0-second plate stays covered. It shows how many changes happen with no UV at all (copying errors).
